# make-knowledge-cards

## 1. 项目解决什么问题

长文章读完后很难复习：重点散落在段落里，手工做卡片又容易抄成大段笔记。这个 skill 把用户提供的正文压缩成少量可独立复习的知识卡片，强制一卡一点、原文有据；信息不足时少输出，不靠拆句、重复或加“总结卡”凑数量。

适用于概念科普、操作教程、观点评论、结构较乱的笔记等纯文本；不负责把网页、PDF 或其他格式转换成文本。

## 2. 主要功能

### 输入

- 对话中直接粘贴的正文。
- 本地 `.md` / `.txt` 文件，只读，不修改原文件。
- 中英文或混排文本，卡片语言跟随原文。

### 输出

- 目标 5-8 张卡片；独立且重要的知识点不足时，输出实际数量并说明原因。
- 每张卡包含：标题、核心知识、简明解释，以及例子或自测（自测含参考答案）。
- 默认直接在对话中输出 Markdown；文件输入在用户明确要求保存时，写到当前工作目录的 `<源文件名>-cards.md`，不覆盖原文件。
- 输出先写一行 `共 N 张卡片`；少于 5 张时说明原因。

### 内容质量约束

- 一张卡只讲一个知识点；同一问题的并列项可以同卡，不同问题不混卡。
- 删除重复内容，不把同一知识点换说法拆成多张卡。
- 不编造原文没有的数字、因果、结论或例子；不确定、缺失或前后矛盾的内容不补全、不替作者裁决。
- 观点评论类写成“作者主张 + 原文依据”，不把观点写成客观事实。
- 不添加“背景卡 / 总结卡 / 延伸卡”。

### 边界（以下不是功能）

- 网页抓取、URL 链接。
- PDF、Word、PPT、图片 OCR。
- Anki / apkg 等卡片软件格式导出。
- 图形界面或交互式应用。

遇到这些输入时，请先转换成纯文本，或直接粘贴正文。

## 3. 安装方法

**前置条件：** 一个支持 `SKILL.md` 技能的 Agent 客户端，并且客户端能读取本地文件。本 skill 不含脚本，不需要额外安装依赖。

**安装步骤：**

1. 复制整个 `skills/make-knowledge-cards/` 目录，不要只复制 `SKILL.md`。
2. 放到客户端的技能目录：
   - Trae 项目级：`<项目>/.trae/skills/make-knowledge-cards/`
   - Codex 用户级：`~/.codex/skills/make-knowledge-cards/`
   - 其他支持 Agent Skills 的客户端：放到其用户级或项目级 skills 目录，以客户端设置为准。
3. 重新加载客户端或新开会话，让技能被索引。

本仓库中的 `skills/make-knowledge-cards/` 是开发和分发位置，不一定是客户端的加载位置。

```text
skills/make-knowledge-cards/
├── SKILL.md          # 卡片规则、输入边界、工作流
└── agents/
    └── openai.yaml   # 界面显示名称、简介、默认提示
```

`agents/openai.yaml` 只影响界面显示，卡片生成规则都在 `SKILL.md`。如需检查技能结构，可用 skill-creator 的 `quick_validate.py`；它不是运行依赖。

## 4. 使用方法

1. 安装并重载后，显式调用 `$make-knowledge-cards`，或直接提出“把文章做成知识卡片”。
2. 粘贴正文，或给出 `.md` / `.txt` 文件路径。
3. 在对话中查看 Markdown 卡片；需要落盘时明确说“保存 / 导出”。

示例请求：

```text
用 $make-knowledge-cards 把下面这段文字做成知识卡片：
<粘贴正文>
```

```text
把 notes.md 做成知识卡片。
```

文件输入在要求保存时写到当前工作目录的 `<源文件名>-cards.md`，不覆盖原文件；粘贴文本默认只在对话中输出。

## 5. 输入输出示例

输入：

```text
光合作用是绿色植物利用光能，把二氧化碳和水转化成有机物并释放氧气的过程。
它发生在叶绿体中，叶绿素负责吸收光能。
光合作用为几乎所有的生态系统提供能量来源。
```

输出（节选，共 3 张）：

```markdown
共 3 张卡片（原文可用知识点不足 5 个，未凑数）

### 1. 光合作用的定义

**核心知识：** 光合作用是绿色植物利用光能，把二氧化碳和水转化成有机物并释放氧气的过程。

**简明解释：** 这句话同时交代了条件（光能）、原料（二氧化碳和水）和产物（有机物、氧气）。

**自测：** 光合作用的原料和产物分别是什么？
**参考答案：** 原料是二氧化碳和水，产物是有机物和氧气。

### 2. 光合作用的发生场所

**核心知识：** 光合作用发生在叶绿体中，由叶绿素吸收光能。

**简明解释：** 叶绿体是场所，叶绿素负责吸收光能，两者分工不同。

**自测：** 叶绿体和叶绿素在光合作用中分别起什么作用？
**参考答案：** 叶绿体是发生场所，叶绿素负责吸收光能。
```

两张卡分别只讲“定义”和“发生场所”，没有把叶绿体、叶绿素拆成多张卡，也没有补充原文之外的例子。
